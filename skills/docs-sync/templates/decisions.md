# Design decisions log

A running log of non-obvious decisions: the *why* behind choices that aren't evident from reading the code. Add an entry whenever a decision is made that a future reader would otherwise have to re-derive, or might accidentally reverse.

Newest entries at the top. Entries are never edited to change history. If a decision is reversed, add a new entry with a `Supersedes:` line.

Format:

```
## <short title> - YYYY-MM-DD

Decision: <what was decided>
Why: <the reasoning, constraints, and alternatives ruled out>
Affects: <files/systems this touches, for future search>
Supersedes: <title of the older entry, only if this replaces one>
```
